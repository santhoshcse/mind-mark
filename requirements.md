# Mind Mark

I have more than 1000 of bookmarks in my chrome synced with google account. Don't know the exact count. But it could be multiple thousands.

I want to build an application to sync and manage the bookmarks.

- Sync Bookmarks from Chrome
- Catagorization
- Tags
- Vectorize
- Indexing
- Search
- Filter
- Deduplicate / Merge
- Import (json, csv)
- Export
- Health Check
- Config
- Concurrency
- Multi-Profile
- Bookmark Tree

Support (for now):

- Windows
- Chrome
- Local DB (SQLite)

Future:

- Multiple OS
- Online/Cloud DB (for both metadata and vector)
- Multiple Browser
- Bidirectional sync
